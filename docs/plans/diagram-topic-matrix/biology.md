The repository has no Biology admin-topic taxonomy, so the IDs below are planning IDs derived from all ten units in the official NMC syllabus, not official NTA topic IDs or an existing runtime registry. Compound source clauses are split/grouped at a declared editorial grain; source keywords, named disorders and restricted depth remain visible. The subject reviewer must confirm this grain and diagram-need hypotheses before freezing the evaluation denominator. This file does not restore legacy chapters absent from the selected syllabus.

Source keys, scope codes and evidence rules are defined in [the matrix index](index.md). This is documentation only; every topic remains **topic audit pending**. Allocation percentages count unique assigned checklist rows, not passing scenes or future question success.
