  use canonical `(2*pi*r)/T` and then `v*v/r` for the period-derived state.
  No rounding of authority values.
- `uniformCircularSourceBinding.ts`: regenerate all quantities and structure;
  compare source question, radius/input quantities, row IDs/symbols/units,
  constructions, assertions, identities, labels, roles and annotations strictly.
  The only numerical allowance is the local binary64 forward-error bound
  `gamma(8)=8u/(1-8u)`, `u=EPSILON/2`, for derived `v`, `omega`, `a_c`, after
  exact input/structure binding. Given speed, angular rate and acceleration
  are excluded from that allowance. Tiny/subnormal or enormous derived values
  cannot use the proof. Existing plan-based admission behavior is retained.
  `canonicalizeUniformCircularSourceDocument(document, question)` validates
  first, then returns canonical source quantities for parent save/read glue.
  This is not a provenance/authenticity claim for a submitted derived float:
  differences within the mathematical error budget must be replaced by the
  independently regenerated value, not carried as a new authority.
- New `uniformCircularSourceIR.ts`:
  `await buildUniformCircularSourceFallback(question)` returns a complete
  `problemIR`, `turnPlan`, and local `solverResult`, or null. It consumes the
  entire setup and request, supports one body with explicit radius plus speed
  OR period, and binds every requested speed/angular speed/centripetal
  acceleration/period. All four state values have variable-free expression
  trees, explicit solver result bindings, dependency IDs and exact agreement
  with the source evaluator. Facts carry exact question quotes/spans; body,
  circle/path and centre entities remain in the representation intent.
  No generic/mock/minimal IR and no extra figure cue. Use only for an absent
  usable formulation; do not replace/drop an existing full IR.
- `relativeMotionSource.ts`: whole bounded catch/travel request grammar binds
  the pursuer/reference and `requests.travelActors`. Both spellings of
  travelled/traveled work. Unknown/self actors, extra request clauses,
  conditions, delays, unsupported units and extra bodies decline. Existing
  observer/frame/sign/timing grammar and impossible encounter outcomes remain.
  `relativeMotionSourceEntityBindings(question, problemIR)` independently
  resolves actual IR identities against parsed source actors: the captured
  `trainA`/`Train A` -> `A`, `trainB`/`Train B` -> `B`. It rejects duplicate,
  missing and foreign actors. It supplies joins, not obligation exemptions.
- `motionPlanAgreement.ts`: `v_A_ms`/`v_B_ms` conversion aliases and actor-bound
  `d_A`, `s_A`, `distance_A` (and reference equivalents), computed as
  `abs(v_actor)*t` at a real initial/future encounter. Another actor's allowed
  distance cannot satisfy the named role. Existing correction seam is reused.
