Input contract the dispatch must preserve:

- `line_relation` mode is `slope` or `relations`.
- `section_point` mode is `internal`, `external`, or `midpoint`.
- `axis_translation` direction is `toNew` or `toOld`; target is `point`, `line`, `circle`, or `conic`. Conic input also requires a witness on the source curve. Exam scope is on `analyticLine.translation.examScope` (`jeeMain: "application"`, `jeeAdvanced: "listed"`, `shiftOfOrigin: true`).
- `line_equation` form is `general`, `pointSlope`, `twoPoint`, `intercept`, or `normal`. Normal input is `{ alpha, p }` with `p` the signed perpendicular distance. Vertical point-slope uses `slope: null`.
- `line_intersection_angle` and `line_concurrence` take lines `{ a, b, c }`.
- A finite common point is returned only when that point satisfies every supplied line. A zero coefficient determinant is stored and is not itself the certificate.
