Kernel limits: degree <=128, each power <=64, AST <=128 nodes/depth24,
1024-bit reduced rationals, <=300000 convolution operations, expression
source <=512 characters. Scene/source scope additionally limits displayed
exponents to 0..15 (16 rows), header to 100 characters, exact coefficient
labels to 32 characters, numeric adapter magnitude to 1e12 and nonzero
magnitude to at least 1e-100. Nonzero source literals cannot silently round
or underflow into a different literal.

The current bounded source grammar accepts `Expand <expression>.` or a
coefficient-of-unit-monomial request in the expansion of a complete expression,
optionally with `is`, four numeric A–D options and an answer marker. All source
suffixes are consumed. The native OCR dialect is enabled by a duplicated
italic `𝑥𝑥` glyph pair: pairs collapse to x and baseline digit runs after x or
closed parentheses become powers. Normalizations are recorded by the reader;
raw question text is unchanged. Other OCR dialects are explicit gaps.

Full-IR admission currently requires one polynomial `other` entity (optional
label P(x)), exactly one complete given function expression, source-bound
given/requested facts, conceptual intents on that entity and, for coefficient
requests, exactly one scalar evaluate ask with an explicit unit `1` and actual
quantity ID. Its closed result expression is checked against independently
computed source authority. No request name, symbol similarity, metadata flag,
chapter label or authored transcription provides numeric authority. Unknown
constraints/assumptions, extra entities/expressions/asks and other representation
intents decline. Nonempty constraint arrays are inspected and declined, never
discarded. The fixtures model this full graph; they are **not captured live
planner IR** and do not claim the parent already emits this profile.
