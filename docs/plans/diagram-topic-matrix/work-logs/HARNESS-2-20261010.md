## General rule and implementation

A missing physical value is drawn as its symbol in a normalized qualitative representative. Normalized coordinates and curve coefficients prove shape, not a physical measurement. Numeric givens remain authoritative. Truly missing source topology, apparatus or an original figure can still make a faithful representation impossible.

The old quantity validator already admitted symbol-only labels and no scene quantities. The main obstruction was the prompt's world-coordinate authority wording and numeric-only physical operators. The projectile archetype's metric slots were another boundary; it cannot supply an exact plan-bound trajectory without values. This patch enables a generic planner representative instead of stocking those slots with values or bypassing validation.

- Prompt explicitly distinguishes normalized geometry from physical quantities, limits symbolic scenes to `qualitative_verified`, and makes source evidence outrank advisory invariants and examples.
- Requests with a known empty `TurnPlanV3.givens` can use existing `circle`, `function_curve` and `curve_anchor` contracts. Numeric and chemistry family scopes stay intact. No new operator, topic template, routing table or permissive validator was added.
- A foreign document declaring nonmetric or qualitative authority cannot be promoted to exact by metric assertions over its display geometry. Declarations can lower authority, never raise it.
- Measured-label agreement now sees compound units, powers, prefixes, signed and scientific numbers. It retains case-sensitive SI scaling and rejects unsupported stock speed, gravity, angle and range labels.
- Small additive private run fields retain decline statements on request outcomes and every construction's bounded arguments in rejected candidates. The shared base's evidence hooks also retain discarded speculative responses and authority revalidation. Candidate rejection does not claim that each individual operator was faulty.
- `production-regressions.jsonl` starts with authored projectile wording. Its independent gate reads that row, compiles a symbol-only representative, checks u/θ/R, enforces qualitative authority and rejects stock values.

The first 35 rows used the initial global generic-geometry addition. Final checks then narrowed it to known plans with no numeric givens, restored the explicit empty-array instruction for text-only output, added legacy decline extraction, fixed prefix conversion edge cases and compacted repair catalog metadata. The owner-approved remaining 15 rows used that revised version. Of the first 18 accepted figures, 16 have no numeric givens; the two numeric figures use only point/segment/vector operators, unaffected by the narrowed addition. Both source snapshots are preserved. This mixed-version 50-row table is experiment evidence, not a fresh final-version rerun of the first 35.

The final branch is rebased on the shared harness changes, including strict candidate-selection safeguards. No calls were repeated to remeasure those separately owned changes. Live defaults remain off.
