# Advanced extra-Chemistry topic-to-agent matrix

Version: **JEE Advanced 2026 extra-Chemistry editorial checklist, 2 October 2026**. This decomposes the seven CA groups in the root plan, covering the nine supplemental Chemistry macro headings. IDs are editorial planning IDs, not additions to runtime taxonomy. Already mapped primary Chemistry topics remain in chemistry.csv; their Advanced scope/variants belong there, so this is not an independent claim that every Advanced requirement is enumerated in these extra rows. Do not add the nine overlapping macro IDs in supplemental.csv to this checklist denominator. Source-specific limitations, including drug structures excluded and sweetener names only, stay explicit.

Source keys, scope codes and evidence rules are defined in [the matrix index](index.md). This is documentation only; every topic remains **topic audit pending**. Allocation percentages count unique assigned checklist rows, not passing scenes or future question success.
