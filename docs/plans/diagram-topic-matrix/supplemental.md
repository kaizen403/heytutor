# Supplemental taxonomy topic assignments

This preserves **all 13 exact supplemental-unit topic IDs** from the current repository taxonomy: three Mathematics, one Physics and nine Chemistry. They are outside the 521 core/132 primary-Chemistry denominator. Nine Chemistry macro rows overlap the Advanced chapters decomposed in [advanced-extra.md](advanced-extra.md); those macro IDs and their editorial children must never be added together as independent syllabus topics. A `review` scope marks a broad mixed row requiring narrower source decisions. Taxonomy aliases do not turn every legacy variant into an official requirement. SX packets remain optional historical-scope work unless explicitly selected.

Source keys, scope codes and evidence rules are defined in [the matrix index](index.md). This is documentation only; every topic remains **topic audit pending**. Allocation percentages count unique assigned checklist rows, not passing scenes or future question success.
