This optional lecture path uses a previously generated image to choose an engine
color palette. Scene-engine reconstructs the scientific figure from the original

## Configuration

The feature defaults off. To enable it in a test environment, set
`SCIENTIFIC_STYLE_LECTURES=on` and `SCIENTIFIC_STYLE_SAMPLE_PATH` to an existing PNG
on the server. The sampler bounds and decodes the file, selects an engine palette
and records its SHA-256. An unavailable or invalid sample disables acquisition.
No student request generates an image or incurs an image-generation charge.

its verification tier and metric status. A supplied source stamp, palette or
correct-looking image supplies no scientific authority. Numeric values retain
their source, physical field, unit and accepted-plan identity.

charges, energy, impact parameter and displayed results. The other typed atomic
