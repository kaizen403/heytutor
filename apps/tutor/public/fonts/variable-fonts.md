# Local interface fonts

Inter, Caveat, and Fraunces are unmodified variable fonts from [Google Fonts](https://github.com/google/fonts/tree/9710da1eacb3be272583c3224dcb70f9da6eadbb/ofl), commit `9710da1eacb3be272583c3224dcb70f9da6eadbb`. The original TTFs were losslessly encoded as WOFF2 with FontTools; all original axes and glyphs are retained. Adjacent `*-OFL.txt` files contain their SIL Open Font Licenses.

The root layout uses `next/font/local` so builds and visitors do not depend on Google Fonts network availability.
