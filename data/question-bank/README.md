# Historical question bank

This directory holds the small, reviewable source of truth for historical exam
questions. Raw PDFs, extraction text, caches, and the generated SQLite database
are local artifacts and are ignored by the adjacent `.gitignore`.

## Tracked records

- `manifest.jsonl` contains one source document per line. Each record pins the
  publisher provenance, year, exam, session, set, subject, source URL, paper
  identity, archive-member identity, page count, SHA-256, and ingestion status.
- `questions.jsonl` contains canonical extracted questions. Page and question
  numbers live in `source_refs` because one deduplicated question can occur in
  several papers.
- `source-catalog.json` is the issuer-verified acquisition allowlist. Its
  `known_gaps` array is part of the result: missing years and shifts are never
  silently treated as complete.
- `classification-rules.json` contains deterministic, reusable concept rules
  for the two initial chapter scopes. Difficulty remains `null` unless an
  authoritative source supplies it.
- `syllabus-taxonomy.json` is the versioned framework/unit/topic taxonomy for
  the full Mathematics and Physics syllabus. `syllabus-rules-*.json` contain
  subject-gated lexical evidence for regular units; historical supplemental
  units use only their complete topic labels and aliases.
- `schemas/` documents the versioned record contracts. The stdlib CLI performs
  validation without requiring a JSON Schema package.
- `reports/` is trackable audit output. Pass `--report` explicitly when a run
  should leave a committed report.

Use `not_applicable` for a real source that has no session or set. A new manifest
row normally starts with `"sha256": null` and `"status": "planned"`; acquisition
fills the hash, page count, and retrieval timestamp. ZIP members retain both the
container URL/hash and the member path. Example shape:

```json
{"schema_version":"question-bank-document/v2","document_id":"jee-advanced-2025-paper-1-english","provenance":{"publisher":"JEE (Advanced) Joint Admission Board","source_type":"official","retrieved_at":null,"notes":null},"year":2025,"exam":"JEE Advanced","session":"Paper 1","set":"English","subject":"Physics, Chemistry, Mathematics","source_url":"https://jeeadv.ac.in/past_qps/2025_1_English.pdf","paper":{"stage":"main","paper_number":"1","exam_date":null,"shift":null,"mode":"computer_based","language":"English","accessibility_variant":"standard"},"artifact":{"media_type":"application/pdf","page_count":null,"container_url":null,"container_sha256":null,"member_path":null},"sha256":null,"status":"planned"}
```

Question rows are generated by the extraction command and have this shape:

```json
{"schema_version":"question-bank-question/v3","question_id":"q_<sha256>","text":"...","content_sha256":"<sha256>","topic":null,"subtopic":null,"difficulty":null,"answer":null,"status":"extracted","source_refs":[{"document_id":"...","document_sha256":"<pdf-sha256>","page_number":3,"page_end":3,"question_number":"7","subject_context":"Physics","extraction_method":"pdftotext-layout","extracted_text_sha256":"<question-snippet-sha256>","extraction_artifact_sha256s":["<whole-text-artifact-sha256>"]}]}
```

The snippet hash identifies the exact question text from one source occurrence;
the artifact hashes record every whole-text extraction that produced it. Re-OCR
therefore does not invent a second paper appearance. `subject_context` records
the nearest explicit subject heading in a combined paper. For headerless JEE
Advanced papers, the batch may assign it only when exactly three END-delimited
blocks have a decisive one-to-one PCM lexical assignment; the build report
retains the per-block scores and winning margin. It is `null` when neither that
evidence nor a trustworthy heading exists. Single-subject documents may still
use their document-level subject for classification.

Existing v2 question JSONL can be upgraded atomically with
`python3 tools/question-bank/qbank.py migrate-v3`. Migration records an unknown
context as `null`; it does not guess a subject for combined papers.

`reviewed` is deliberately strict: topic, subtopic, difficulty, and answer must
all be populated. Extraction and keyword classification never mark a question
reviewed.

## Local artifact layout

The CLI creates directories as needed:

```text
raw/       downloaded PDFs
staging/   verified pre-import acquisition artifacts and sidecars
text/      OCR or other form-feed-delimited extraction text
cache/     optional downloader/OCR caches
build/     generated question-bank.sqlite
           generated question-syllabus.jsonl sidecar
           generated question-bank-full.sqlite syllabus index
reports/   optionally committed run reports
```

Raw paper bytes and full extraction text are intentionally ignored. Public
availability is not treated as permission to redistribute an exam publisher's
bulk corpus. The tracked manifest, hashes, catalog, schemas, rules, and aggregate
reports are sufficient to reproduce and audit a local build.

## NTA JEE Main staging

`python3 tools/question-bank/nta_jee_main_acquisition.py` adds a deterministic
staging layer between the reviewed official NTA inventory report and any later
manifest import. Its default inputs are:

- `data/question-bank/reports/nta-jee-main-coverage-2026-08-10.json`
- `data/question-bank/nta-jee-main-official-schedule.json`

Its default outputs are:

- `data/question-bank/staging/nta-jee-main/` for staged PDFs plus stable sidecars
- `data/question-bank/reports/nta-jee-main-acquisition-2026-08-10.json`

Use `--dry-run` to build only the deterministic plan/report. Real runs stream to
`.part`, enforce `--max-file-bytes` and `--max-total-bytes`, resume only on a
valid HTTP 206 `Content-Range`, and verify `%PDF-`, page count, SHA-256, and
the first-page header before a file becomes canonical. This command never edits
`manifest.jsonl`, `raw/`, or `text/`.

See `tools/question-bank/README.md` for commands and review boundaries.

The full-syllabus build never edits canonical question-v3 rows. It emits one
`question-bank-syllabus-assignment/v1` record per question, preserving ranked
evidence and explicit abstentions for low scores, close margins, missing
combined-paper context, and cross-source subject conflicts. Overlapping lexical
signals are counted once; uncorroborated legacy topic projections and questions
with strong evidence for a second unit enter the review queue. Chemistry
remains an explicit `out_of_scope` result. The generated full SQLite database
retains the ordinary documents/questions/source index and adds normalized
syllabus framework, unit, topic, assignment, candidate, evidence, and review
tables.
